# Logo y firma por defecto de FEEP

Si colocas aquí los ficheros de imagen, al arrancar el servidor se activan
automáticamente como **logo y firma predeterminados** del propietario (no hace
falta subirlos desde la app). Gracias al fallback de renderizado, todos los
certificados —incluidos los 11 sembrados— saldrán con ellos.

Nombres admitidos (se usa el primero que exista):

- **Logo:** `logo.png` · `logo.jpg` · `logo.jpeg` · `logo.webp`
- **Firma:** `firma-secretario.png` · `firma.png` · `firma-secretario.jpg` · `firma.jpg`

Recomendado: PNG con **fondo transparente** para la firma. Tamaño moderado
(el logo se muestra a ~230 px de ancho; la firma a ~160 px).

Nota: nunca sobrescribe un logo/firma que ya hayas guardado desde la app; solo
rellena lo que falte.
